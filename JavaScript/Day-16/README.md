# Day 16 - JavaScript Sum of Digits and Prime Number

## Overview

Practiced finding the sum of digits of a number and checking whether a given number is a Prime Number using JavaScript.

The task focused on using a `while` loop for digit extraction and a `for` loop with conditions to determine whether a number is prime.

## Practice

Performed the following operations:

- Calculated the sum of digits of a number
- Extracted digits using the modulus operator
- Used `Math.floor()` to remove the last digit
- Counted the number of divisors of a number
- Checked whether the number has exactly two divisors
- Displayed whether the number is a Prime Number
