# Day-04 - JavaScript

## Overview
Continued learning JavaScript by practicing string manipulation and character-based operations. Created different tasks to work with strings, loops, conditions, and built-in string methods.

## Topics Covered
- String Manipulation
- String Length
- String Indexing
- Reverse a String
- Palindrome Checking
- Vowels
- Consonants
- Counting Vowels and Consonants
- `toLowerCase()`
- `toUpperCase()`
- `split()`
- `charAt()`
- `slice()`
- `for` Loop
- Conditional Statements

## Technologies Used
- HTML5
- JavaScript

## Practice
Created JavaScript programs to perform different string operations. Practiced reversing strings, checking whether a string is a palindrome, finding vowels and consonants, counting vowels and consonants, and capitalizing the first letter of each word.
