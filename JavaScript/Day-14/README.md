# Day 14 - JavaScript Armstrong Number

## Overview

Practiced checking whether a given number is an Armstrong Number using JavaScript.

The task focused on extracting each digit of a number, calculating the sum of the cubes of its digits, and comparing the result with the original number.

## Topics Covered

- JavaScript Variables
- While Loop
- Modulus Operator
- Division
- `Math.floor()`
- Digit Extraction
- Arithmetic Operations
- If-Else Condition
- Number Comparison
- `document.write()`

## Technologies Used

- HTML5
- JavaScript

## Practice

Performed the following operations:

- Stored a number in a variable
- Extracted each digit using the modulus operator
- Calculated the cube of each digit
- Added the cubed values
- Compared the calculated sum with the original number
- Displayed whether the number is an Armstrong Number or not

## JavaScript Concepts Used

- `let` / variables
- `while` loop
- `%` operator
- `Math.floor()`
- Arithmetic operators
- `if-else`
- `document.write()`
