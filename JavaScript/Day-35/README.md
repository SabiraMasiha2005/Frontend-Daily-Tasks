# Day 35 - JavaScript Text Statistics Analyzer

## Overview

Created a Text Statistics Analyzer using HTML and JavaScript to analyze a given sentence and calculate different text statistics.

## Topics Covered

- JavaScript Classes
- Constructor and Objects
- Functions
- Loops
- Conditional Statements
- String Manipulation
- Character Analysis
- DOM Manipulation
- User Input Handling

## Technologies Used

- HTML5
- JavaScript

## Practice

Performed the following operations:

- Counted total characters
- Counted total words
- Counted spaces
- Counted vowels
- Counted consonants
- Counted digits
- Counted special characters
- Found the longest word
- Displayed the analysis dynamically
