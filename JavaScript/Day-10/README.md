# Day-10 - JavaScript Default & Rest Parameters

## Overview
Practiced JavaScript function parameters by working with default parameters and rest parameters. Learned how default values can be assigned to function parameters and how rest parameters can accept multiple arguments.

## Topics Covered
- JavaScript Functions
- Default Parameters
- Rest Parameters
- Function Arguments
- `return` Statement
- `for...of` Loop
- DOM Manipulation
- `getElementById()`
- `innerHTML`

## Technologies Used
- HTML5
- JavaScript

## Practice
Created JavaScript programs to demonstrate default parameters and rest parameters. Used a default value in a function and calculated the total of multiple values using the rest parameter.
