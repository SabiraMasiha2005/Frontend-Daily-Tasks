# Day 56 - JavaScript Smart Job Application Tracker

## Overview

Created a Smart Job Application Tracker using HTML and JavaScript to manage job applications, update application statuses, search companies, track selected jobs, and compare salaries.

## Topics Covered

- JavaScript Classes
- Constructor and Objects
- Arrays
- Loops
- Conditional Statements
- Job Application Management
- Status Tracking
- Company Search
- Salary Comparison
- Job Addition and Deletion
- DOM Manipulation

## Technologies Used

- HTML5
- JavaScript

## Practice

Performed the following operations:

- Stored and displayed job application details
- Added new job applications
- Updated application statuses
- Searched jobs by company name
- Displayed selected applications
- Found the highest salary
- Counted applications by status
- Deleted job applications
- Validated job IDs and salaries
