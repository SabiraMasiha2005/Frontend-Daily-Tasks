# Day-08 - JavaScript

## Overview
Continued learning JavaScript by practicing classes and objects. Created an SBI customer details program using a class, constructor, object creation, and object properties.

## Topics Covered
- JavaScript Classes
- Constructor
- Objects
- Object Properties
- `this` Keyword
- Creating Objects using `new`
- DOM Manipulation
- `getElementById()`
- `innerHTML`

## Technologies Used
- HTML5
- JavaScript

## Practice
Created an SBI customer details webpage using a JavaScript class. Defined customer properties such as name, account number, branch, and account type using a constructor. Created multiple customer objects and displayed their details dynamically on the webpage using DOM manipulation.
